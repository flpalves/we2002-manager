# Table

Tabela densa, o coração do manager: células de 13px em Barlow com números tabulares, cabeçalho em Chakra Petch MAIÚSCULAS sobre `painel-fundo`, zebra com `painel-alt`.

- Linha do clube do usuário: `<tr class="we-destaque">`.
- Zona da tabela (Libertadores, Sul-Americana, rebaixamento) pinta só o número da posição, com `info`, `atencao` e `negativo`.
- Tabelas largas ficam numa caixa com `overflow-x: auto`; o cabeçalho pode ser `position: sticky`.

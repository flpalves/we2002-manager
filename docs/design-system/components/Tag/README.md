# Tag

Etiqueta curta de situação ou tipo, em Chakra Petch 10px MAIÚSCULAS, texto escuro sobre cor clara (legível nos dois temas).

- Situação na convocação: `we-tag--tit` (TIT), `we-tag` (RES), `we-tag--fora` (FORA).
- Tipo de notícia: `--negativo` (LESÃO), `--atencao` (PROPOSTA), `--info` (MERCADO), `--diretoria` (DIRETORIA), `--positivo` (ELENCO), padrão (RESULTADO).
- Uma ou duas palavras. A cor sempre repete o que o texto diz; nunca use só a cor.

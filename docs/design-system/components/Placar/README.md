# Placar

Placar digital do confronto (`we-placar`): números amarelos (`placar-texto`) sobre preto, borda em baixo-relevo, Chakra Petch 34px tabular. Antes do jogo mostra "–  x  –".

Ladeado pelos escudos (`we-escudo`, 56px; no placar menor de um confronto, `we-escudo--g`). Tamanhos, escudo provisório e regras de uso: ver o componente Escudo.

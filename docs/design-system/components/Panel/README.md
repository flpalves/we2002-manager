# Panel

Caixa de conteúdo das telas: corpo `painel`, topo iluminado (`linha-forte`) e base seca (`sombra-painel`), cantos `radius-md`.

- `we-panel__head`: cabeçalho em Chakra Petch MAIÚSCULAS. Cinza por padrão; `we-panel__head--clube` só para o painel principal da tela (ex.: "Próximo jogo").
- `we-panel__body`: padding `space-2`. Para pares rótulo/valor use `we-kv` com `we-lb` e `we-vl` (`--positivo`, `--atencao`, `--negativo` quando o valor tem significado).
- Painéis se organizam numa grade com `gap-painel` (10px).

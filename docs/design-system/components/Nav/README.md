# Nav

Menu lateral fixo de 180px sobre `painel-fundo`, itens em Chakra Petch 13px. O item da tela atual leva `aria-current="page"` e fica na cor do clube; com o ponteiro, um filete da cor do clube aparece à esquerda.

Ordem padrão: Início, Elenco, Escalação, Treino, Calendário, Competições, Mercado, Finanças, Clube e diretoria, Notícias; no pé, Editor do pacote, Configurações, Salvar / Carreiras. No gamepad, LB/RB trocam de seção.
